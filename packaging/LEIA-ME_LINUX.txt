GURPS 4e Calculadora — Linux x86-64
=================================

1. Extraia todo o ZIP.
2. Clique duas vezes no arquivo "GurpsCalculadora".

O programa não requer instalação de Python nem uso do terminal.
Se o gerenciador de arquivos bloquear a execução, abra Propriedades >
Permissões e permita executar o arquivo como programa.

A versão aparece no aplicativo. A compatibilidade com distribuições mais
antigas que a usada para a compilação não está garantida.

O menu Exibir permite mudar tema, cores, fonte e navegação. O programa
tem interfaces em português e inglês e unidades métricas e imperiais.
Os catálogos incorporados não incluem PDFs nem imagens dos livros.
Preferências e presets são gravados na pasta de dados do usuário.

English: Extract the complete ZIP and double-click "GurpsCalculadora".
If blocked, enable execution in the file's Properties > Permissions.
Python and terminal use are not required.
