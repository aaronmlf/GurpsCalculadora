GURPS 4e Calculadora — Windows x86-64
===================================

1. Extraia todo o ZIP.
2. Clique duas vezes no arquivo "GurpsCalculadora.exe".

O programa não requer instalação de Python nem uso do Prompt de Comando.
O executável não tem assinatura digital. Baixe somente da página oficial
do projeto e confira a integridade antes de executar. Consulte o
release.json para saber se a validação ocorreu em Windows nativo ou Wine.

A versão aparece no aplicativo. O menu Exibir permite mudar tema, cores,
fonte e navegação. O programa tem interfaces em português e inglês e
unidades métricas e imperiais. Os catálogos incorporados não incluem PDFs
nem imagens dos livros. Preferências e presets são gravados na pasta de
dados do usuário.

English: Extract the complete ZIP and double-click "GurpsCalculadora.exe".
No Python or command prompt is required. The executable is unsigned;
download from the official project and check the published checksum.
